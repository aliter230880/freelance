🚀 КАК ЗАПУСТИТЬ (для не-кодера)

ЛОКАЛЬНО (предпросмотр):

1. Открой PowerShell
2. cd E:\AI\AI_folder\unidev-portfolio
3. npm run dev
4. Открой в браузере: http://localhost:5173

НА VPS (публикация):

1. Открой командную строку (cmd)
2. cd E:\AI\AI_folder\unidev-portfolio
3. .\deploy.cmd
4. Жди завершения (2-3 минуты)
5. Открой: https://unidev.space ✨
